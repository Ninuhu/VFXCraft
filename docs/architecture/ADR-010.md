# ADR-010 マテリアル、合成、背景と基本Bloom

状態　採用

対象　T07-Q01〜Q12、OPEN-07、AT-03/04/13/15

## データと座標

基本色と制御点のRGBはLinear sRGB、透明度はStraight Alphaで保持する。寿命は生成から消滅までの0〜1。空間は粒子のUV中心を0、上下左右の辺の中点を1とする半径で、角は1にクランプする。同じ設定を2Dと3Dの板に適用する。色とアルファはそれぞれ位置順に線形補間し、端の外側は端点値を使う。空配列は白または1となる。同じ配列内の同位置は拒否する。近接した異なる位置に点を置くと急な変化を作れる。

レイヤーとマテリアルの基本値、寿命、空間、画像テクスチャのRGBと透明度を別々に乗算する。寿命は粒子ごとにCPUで評価し、空間は256サンプルのRGBA8参照表を使う。量子化で極端に近い空間制御点は滑らかになる。画像は非乗算でデコードし、補間時だけ線形色をアルファで重み付けする。完全透明のテクセルの色を輪郭に出さない。

色、透明度、制御点位置、Bloomしきい値は0〜1。各制御点配列の上限を64とし、文書検証と参照表の生成コストを制限する。発光強度は0〜8、共通半径は0〜32表示px。基本Bloomで広く使う強度を含め、極端な強度の飽和と大きなぼかしカーネルの負荷を抑える。半径の既定値は8、しきい値は0.5、強度は0。未知値、範囲外、非有限値、欠落した素材参照は拒否する。

## 描画と合成

T05の2D評価とT06の3D評価・カメラ・頂点生成を再利用する。T07検証では、2Dの正射影と3Dの透視投影を分け、粒子の材質評価を共通のThree.jsシェーダーに集約する。2Dはレイヤー順、3Dは全レイヤーを横断する粒子中心深度順。同じ材質が隣接した範囲だけを一つの描画呼出しにする。材質の切替が多いシーンでは呼出し数が増える。板の交差では単一の中心深度で表せない画素順がある。

背景へ合成する段階でRGBを表示用sRGBへ変換する。以下の C は表示用RGB、a はソースの透明度、D は背景と既描画粒子のRGB。

| 方式 | 不透明な背景でのRGB |
| --- | --- |
| 通常（保存値 `alpha`） | C × a + D × (1 − a) |
| 加算（`additive`） | D + C × a を表示範囲へ飽和 |
| 乗算（`multiply`） | D × (1 − a + C × a) |

3方式とも透明度はsource-overで蓄積する。旧Canvas 2Dのエッジ平滑化や合成丸めと画素単位で差が出ることがある。通常の透明合成を既定とする。

## 選択的Bloomと背景

別パスで材質強度が0を超え、線形RGBの最大成分がしきい値を超える粒子だけを発光源にする。強度を `strength / (1 + strength)` に写像し、8ビット発光バッファで段階差を保つ。発光パスは背景を持たず、背景色、チェッカー、グリッドは発光源に入らない。発光マスクは粒子から加算して作り、手前の非発光粒子による完全な遮光は扱わない。

ピクセル2Dでは粒子本体を論理解像度に描き、2/4/8倍で最近傍拡大する。Pixel Bloomは論理解像度でぼかして最近傍拡大する。Smooth Bloomは表示解像度側で発光を補間・ぼかし、本体の拡大方法を維持する。軽量時はぼかし用バッファの各辺を約1/2にする。粒子数、シード、文書、保存状態、履歴は品質の切替から独立する。

背景はプレビューの入力。共通設定はブラウザの `localStorage`、プロジェクトは項目別の上書きだけを保存し、未設定を `false` や `0` と区別する。利用者共通設定・カメラ・品質は文書履歴の対象外。プロジェクトの設定はT03の編集コマンドで検証し、連続数値入力は確定時に一度だけ履歴化する。

## 互換性と後続工程

論理版4で任意の `Material.appearance` と `Project.preview` を追加し、コンテナ版1を維持する。版1〜3の旧 `gradient` と `hasBloom` は保存し続ける。T05/T06描画では両者が未使用だったため、読込で自動発光や色変化を足さない。明示的な材質編集時に新設定を使う。未対応スキーマと未知フィールドを拒否し、ファイル検証完了までは文書・履歴・素材を置き換えない。

T13は背景を渡さず、正確品質を使用する。無背景時の通常合成と発光画素は検証対象。PNGのStraight Alpha化、加算・乗算の背景依存、外部エンジンの合成契約、線形/HDRの出力はT13で扱う。混在合成を単一PNGで任意の背景へ再現するには情報が足りない。製品UIはT10、共通設定の製品UIはT14、高度BloomはMVP-B後。測定と検証の範囲は[T07検証記録](../T07_VALIDATION.md)を参照。
