# ADR-011 タイムライン、区間補間と発生の決定性

状態　採用

対象　T08-Q01〜Q15、AT-05/07/08/11

## 時間と文書

内部時刻はADR-003の非負整数µs。キーはレイヤー開始からの相対時刻、開始・発生終了・制作尺はプロジェクトの絶対時刻。制作FPSを変更してもµsを保持する。フレーム入力とドラッグのスナップは同じ整数変換を使い、秒入力・シーク・自動再生はスナップから独立させる。フレーム表示は保存値を書き換えない。

TrackはレイヤーIDとプロパティの組で識別する。発生器・マテリアルを共有してもアニメーションはレイヤーごとに適用する。同一トラック内の重複は整数µsで拒否し、別トラックの同時刻は許可する。区間の補間は左キーが所有し、区間指定を省略した場合は従来のトラック既定値を使う。線形は数値・ベクトル・Linear sRGBの成分を補間し、3D姿勢は最短経路Quaternion SLERP、Stepは次のキー直前まで左値を保つ。検索はソート済みキーへの二分探索。文書ごとの索引はWeakMapで保持する。

キーなしは基準値、新規トラックの先頭前・末尾後は端点を保持する。論理版1〜4の既存トラックだけは `beforeFirst: "base"` を付けて従来の先頭前の見た目を保つ。版5の新規トラックは先頭保持を使う。

## 発生と描画

発生期間は `[startUs, emissionEndUs)`。明示終端を持たない旧レイヤーは従来と同じ。Continuousの定数発生は従来の粒子番号計算を使う。時間変化する発生率は、StepまたはLinearの各区間を積分して累積量を保存し、粒子番号の閾値を一次式または二次式で逆算する。初期率が正なら時刻0に最初の粒子を発生させ、初期率が0なら積分が1に達してから発生する。Burstは開始時刻に一度だけ発生し、同時刻を再評価しても追加発生しない。可変発生率のキー上限は毎秒100万、1回の評価候補上限は20万。

寿命・初速・方向・加速度・粒子サイズ倍率は発生時に固定する。発生時のキー評価は最寄りの整数µsを使う。寿命と運動の経過時間は解析的な発生時刻を基準とする。3Dの方向は成分補間後に単位化し、正反対の方向の補間でゼロになる場合は発生器の基本方向を使う。ワールド空間は発生時の発生器・親変換、ローカル空間は現在時刻の発生器・親変換を使う。色、レイヤー・材質の透明度、Bloom強度は現在時刻で評価し、粒子寿命グラデーションと独立させる。Continuous用の発生率キーはBurstに切り替えても文書に残し、Burstの個数には適用しない。

粒子IDと2Dの乱数は発生順の絶対番号とシードから決まる。キャッシュは不変の文書・トラックをキーとし、再生履歴を持たない。任意シークとループ後の同時刻は同じ状態を再構築する。3D透明ソートはT06/T07の全体深度順を維持し、Bloomはレイヤー固有の値を頂点属性で転送する。

## 操作と保存

ループは `[0, durationUs)`、非ループは終端で一時停止、手動シークは終端を含む。壁時計アンカーと経過時間から計算し、速度切替時に現在位置からアンカーを張り直す。停止は0へ戻す。再生速度、ズーム、スクロール、選択、ドラッグ候補を保存と履歴から分離する。

ドラッグの仮位置は画面内だけに持つ。確定時はスナップ後の整数µsで重複を確認し、確認済みの上書きは移動元と移動先を一操作にする。制作尺短縮では範囲外キーの保持、削除、取消を選ぶ。保持したキーは警告・選択・値変更・範囲内への移動ができる。保持は既存の補間曲線を維持するため、範囲内の区間の終点として評価される場合がある。発生期間とキー有効範囲は独立する。尺とキーの削除は一操作でUndoできる。履歴の上限と無効な読込時の扱いは従来どおり。

コンテナ版1、論理版5。新規項目はレイヤー発生終了、追加のTrack対象、左キーの区間補間、旧Track評価互換、尺外保持。カーブ、一括キー編集、高度な離散項目のアニメーションはMVP-B後。製品UIはT10、出力フレームの扱いはT13。
