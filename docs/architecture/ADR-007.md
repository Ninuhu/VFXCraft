# ADR-007 T01の検証環境と性能測定

状態：測定条件を採用。製品の性能目標と最低動作環境は未決（2026-11-05）

初期確認環境はWindows 11上のChrome・Edgeとする。Chromeの自動検証はPlaywrightでインストール済みブラウザを指定する。Chrome・Edgeの手動確認はユーザー報告で完了した。

性能測定は640×360、3D、加算＋Bloom、時刻0.65秒のBurstで行う。100・1,000・5,000粒子について、8フレームのウォームアップ後に30回描画し、GPU完了待ちを含む中央値とp95を記録する。ブラウザ版とWebGLレンダラーも記録する。同期描画時間は通常再生FPSと異なり、この値から最低動作環境や最大粒子数を決定しない。

現時点のSprite方式は粒子ごとの描画コストを含む。負荷が問題になる場合はT05/T06でバッチ化と透過描画順を比較する。製品の測定はT15で、代表端末・画面寸法・素材条件を固定して行う。
