# ADR-008 2D粒子の時刻評価と描画

状態：T05で採用。製品挙動はPROJECT_SPECのT05-Q01〜Q06。高度な形状編集、ランダム範囲・シードの本格UI、3DとBloomは担当外。

## 時刻と運動

一定加速度の解析解を使い、位置は発生座標＋初速×秒＋加速度×秒²÷2で求める。状態を積み上げないため、シーク、逆方向への移動、停止・再生で誤差が蓄積しない。Continuousは粒子番号0の時刻0から発生し、発生率0は発生しない。Burstは開始時に指定数を一度だけ発生する。寿命区間は開始を含み終端を除外する。レイヤー開始前は空の結果を返す。

方向は時計回りの度数でX右正が0度。位置は論理ピクセル、初速は論理ピクセル/秒、加速度は論理ピクセル/秒²。加速度も発生器の基底で指定する。親を含むアフィン変換を合成し、ローカルは評価時の変換、ワールドは各粒子の発生時の変換で原点と運動をワールドへ写す。編集で設定を書き換えた場合は、その新しい文書から過去時刻も再評価する。

点は原点、円は面積に一様、長方形は領域内に一様に配置する。乱数はシードと粒子番号から直接作り、評価順によらない。1回の評価が20万粒子を超える場合は、黙って削らず検証用の安全上限としてエラーを表示する。製品の性能上限は今後の測定で判断する。

## スキーマと互換性

論理スキーマは版2。版1も検証入口で受け付け、現行版の出力に移行する。追加のparticle2dがない2D発生器は速度0、方向0、加速度[0,0]、ローカル空間、シード1、点発生を既定とする。旧版には運動を規定する保存値が存在しないため静止を既定にし、既存の発生率・寿命・基準座標を維持する。3Dに2D専用設定は拒否する。pixelScaleの既定は2、整数1〜64を検証用の許容範囲とする。コンテナ版は1を維持する。版2を知らない旧アプリでは未知版として拒否し、設定の損失を防ぐ。

T04初版の固定バイナリ検体は変更せず、旧文書の読込と現行版への保存往復を検証する。発生器と描画設定のコマンドを追加し、T03の原子的な検証・Undo/Redoを利用する。

## 描画とプレビュー

Canvas 2Dでシミュレーション結果を描画する。ピクセル表示は低解像度バッファに描き、整数倍率でNearest-neighbor拡大し、キャンバス端をクリップする。品質は利用者のプレビュー状態で、文書の保存値に含めない。軽量ではシミュレーション結果を変更せず、各レイヤーの表示粒子を最大1000個に間引く。正確モードを将来の出力の基準にし、出力本体はT13で扱う。

描画ループはrequestAnimationFrameで実行し、Reactは操作時に更新する。ImageBitmapはマウントの所有者が解放し、非同期読込が取消後に完了しても閉じる。バッファもdisposeで解放する。T05検証は ?particles-review で開く。素材本体の所有・保存はT04を再利用する。色の合成詳細、寿命グラデーション、BloomはT07、製品UI統合はT10で扱う。

## 検収

AT-02/03/15の2D該当部分、設定変更のAT-07、保存のAT-11を確認する。単体テストは時刻境界、解析解、形状、シード、空間、親変換、互換性と無効入力。ブラウザ検証は品質、ピクセル倍率と実CPU時間を確認する。性能値は参考測定で、製品の目標値とは分ける。
