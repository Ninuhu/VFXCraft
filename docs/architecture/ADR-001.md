# ADR-001 Web実行環境とテスト

状態：T01の検証基盤として採用（2026-11-05）

Node.js 24.22.1、pnpm 11.25.0、TypeScript 7.0.2（strict）、React 19.3.1、Vite 8.3.5を採用する。直接依存は完全一致とし、推移依存は `pnpm-lock.yaml` に固定する。アプリはブラウザ内で実行し、開発用サーバーはループバックアドレスで待ち受ける。

描画とGPU資源はThree.js側で管理する。Reactは操作状態と表示を扱う。別の状態管理ライブラリやReact Three Fiberを追加すると検証対象が増えるため、必要性が分かる段階で比較する。

純粋な計算・入力検証はNode.jsのテストランナーを使用する。Viteとの統合が必要なテストが増えた場合にVitestを再評価する。ブラウザの保存とGPU描画の検証にはPlaywright 1.64.1を使用し、インストール済みChromeを指定する。整形は既存のEditorConfigに従う。
