# ADR-002 2D・3D描画と透過PNG

状態：T01の検証方式として採用。製品の描画方式は暫定（2026-11-05）

Three.js 0.186.1、型定義0.186.0、WebGL2を採用する。正射影と透視投影を切り替え、Sprite、テクスチャ、合成とBloomの処理を共有する。ピクセル2Dは内部解像度を1/4にし、最近傍で表示する。Canvas 2Dのみで2Dを描く案はGPU要件を避けられる一方、Bloomや出力経路を別に維持する必要がある。両方式の同一条件比較は未実施。

検証用PNGは背景を除いた単一フレームを取り出す。加算・Bloomでは、黒背景の色と通常合成での被覆率を基にアルファを近似し、空白を覆う極低輝度の裾を減衰させる。背景による色差、ピクセル境界、製品出力の合成方式は引き続き検証する。通常のPNGアルファは任意の背景で加算合成を厳密には再現できない。

設定・時刻・PNG Blobは標準IndexedDBで一括保存する。localStorageではBlobを直接扱えないため、画像を含む保存の検証には使わない。読み出した設定と画像を検証してから画面へ適用する。保存形式や世代管理はADR-004の対象とする。
