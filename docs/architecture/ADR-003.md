# ADR-003 編集ドキュメントのモード・座標・時間・スキーマ

状態：T02のユーザー承認に基づき採用（2026-11-05）。対象は論理ドキュメントと検証・評価の基盤。

## モードと座標

- 1プロジェクトは `2d` または `3d` の一方。通常2Dとピクセルアート2Dは2Dの描画設定で区別する。モード変更UIと変換・混在の製品仕様は別途判断する。
- 2DはX右正・Y下正、論理キャンバス左上原点、単位は論理ピクセル。正の回転は度数法で時計回り。X正方向を +90° 回すとY正方向を向く。角度の値は360°で折り返さない。
- 3Dは右手系、Y上正、ワールド原点、単位はワールド単位。親付きレイヤーの変換は親ローカルの値として保持する。2D・3Dのベクトルは型と検証で分け、描画倍率や画面軸の変換はレンダラーの境界で扱う。
- 3Dの保存回転は `[x, y, z, w]` の単位Quaternion。有限かつ非ゼロの入力を正規化し、ゼロ長と非有限値は拒否する。角度入力と表示は内因性XYZ順の度数。表示への逆変換の特異点ではZ角を0とし、同じ姿勢を表す角度を返す。

3D回転はStepまたは最短経路SLERP。`q`と`-q`は同じ姿勢とみなし、内積の符号で補間先を同じ半球に揃える。0°と360°の端点だけでは回転数を表せない。同一軸の一周は途中の姿勢キーで表現し、回転数の独立した保存は将来の拡張判断に残す。オイラー角の保存は角度入力に近いが、回転順と特異点が保存・補間に影響するため、角度は入力境界で扱う。

## 制作時間とキー

- 保存時刻は非負の整数マイクロ秒。制作尺は正の安全整数、レイヤー開始は `0 <= startUs < durationUs`。キーの相対時刻は `0 <= offsetUs <= durationUs - startUs` とし、終端のキーを許容する。ループや出力の終端フレームの扱いはT08/T13で決める。
- 制作FPSの初期値は60。変更可能な正の整数とする。整数マイクロ秒でフレームを区別するため、技術上限を毎秒1,000,000フレームとする。製品UIの選択範囲は別途検討する。制作FPS、実測FPS、出力FPSは独立した値とする。
- 0始まりの絶対フレーム番号から `frame * 1,000,000 / fps` を整数演算で計算する。最寄りのマイクロ秒へ丸め、同距離なら大きい方を採用する。安全整数を超える結果は拒否する。60 FPSのフレーム1/2/60は16,667/33,333/1,000,000 µs。128 FPSのフレーム1は7,813 µs。
- 制作FPS変更は保存済みのキーや開始時刻を書き換えない。フレーム番号を保存するとFPS変更でキーの実時間が変わるため、保存時刻を基準とする。出力の分数FPSや丸めはADR-006で扱う。
- TrackはレイヤーIDと位置・回転・サイズ・色・透明度の組で識別する。キー時刻はレイヤー開始からの相対値で、同一Track内の重複を拒否し、昇順を要求する。制作タイムラインと粒子寿命内の変化は別の評価経路とする。
- レイヤー開始前は非アクティブ。キーがない場合と最初のキーより前は基準値を返す。キーと同時刻は当該値、最後のキー以降は最後の値を保持する。区間のStepは前の値を維持し、Linearは数値・ベクトルの成分を補間する。3Dの回転TrackでのLinear指定はSLERPとして評価する。
- 位置とサイズはモードに対応するベクトル、サイズは非負の倍率。色は各成分が0〜1の非乗算Linear sRGB、透明度は0（透明）〜1（不透明）。色と透明度は独立して補間する。素材の色空間変換、合成やBloomの描画詳細はT07で検証する。

## モデルとスキーマ

Projectはモード、論理版、制作尺、FPSとLayer・Emitter・Material・Track・Assetを所有する。Layerは親子・基準値とグループまたはEmitter参照、Emitterは発生と寿命・材質参照、Materialは素材参照と描画設定、Assetは画像のメタデータを持つ。素材本体の解決にはAsset IDを使用する。Presetは独立したテンプレートProjectと、テンプレート内の必要素材IDを持つ。

UUID v4の形式を検証し、プロジェクト内のIDを種類をまたいで一意にする。UUIDの比較は大文字小文字を区別せず、入力文字列を保持する。採番は作成側の責務とする。Trackは複合識別子を使用する。プリセットのテンプレートは独立した参照範囲を持ち、導入時のID再割当てと素材解決はT12で扱う。

論理スキーマ版1を定義する。外部入力の構造、数値、ID、参照先の種類、階層の循環、キー時刻とモード別の値型を検証し、失敗時は位置付きエラーを返す。読み込んだ値を変更せず、Quaternionの正規化を除き不正値の補正はしない。未対応版は拒否する。将来の旧版対応では明示的な移行後に再検証する。

UI・Three.js・IndexedDBから独立したTypeScriptのデータとして表現する。論理版と`.vcr`のコンテナ版は分け、素材の同梱・物理形式・復元世代はADR-004、3D JSONの外部契約はADR-006で扱う。T01の検証用保存値は製品ドキュメントと別で扱う。

親による開始時刻・表示・ロック・色の継承、再親子化、サイズ0の逆変換はOPEN-05に残す。Emitterや粒子寿命の任意プロパティへのTrack拡張は、現行の5項目の検証に含めない。
