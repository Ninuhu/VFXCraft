## 1. 共通の作業契約

1. [AGENTS.md](../AGENTS.md)、[PROJECT_SPEC.md](PROJECT_SPEC.md)、[DECISION_LOG.md](DECISION_LOG.md)を読み、対象タスクの要件を確認する。
2. 対象リポジトリと既存実装を確認する。存在しない技術構成やブランチを前提にしない。
3. タスクの依存条件を確認する。未決の通常技術判断は小さく検証しADRへ記録する。製品スコープやUI配置の変更は独断で決めない。
4. 動く最小単位を実装し、その変更に必要な確認を実施する。大規模な先行抽象化や将来AIの実装を入れない。
5. 要件ID、検証結果、残件、次のタスクを短く記録する。未実施の確認を合格と書かない。

本計画は実装リポジトリへの引き継ぎ資料。この文書作成の段階では、アプリ作成・GitHubへの送信・公開は行っていない。
