# T01 Edge手動確認

リポジトリのルートで `pnpm install --frozen-lockfile` と `pnpm dev` を実行し、Edgeで `http://127.0.0.1:5173/` を開く。保存と復元では同じプロファイルとURLを使う。試験日は実施日に記録する。

| 操作 | 期待結果 |
| --- | --- |
| 通常2D → ピクセル2D → 3Dビルボード | 粒子が描画され、ピクセル2Dでは粒子の輪郭が粗い格子になる |
| 3Dで左ドラッグ・右ドラッグ・ホイール → カメラリセット | 回転・平行移動・ズームが働き、初期視点へ戻る |
| 加算・Bloomをそれぞれ切り替える | 粒子の重なりや発光の広がりが変化する |
| 3D・加算・Bloomを選んで一時停止し、透過PNGを出力 | 640×360のPNGを開ける。透過表示で背景と発光の裾を確認できる |
| ブラウザに保存 → ページ再読み込み → 保存データを復元 | 描画設定と保存済みPNGが復元される |
| Edgeを完全に終了して同じURLを開き、再度復元 | 同じ保存枠から設定とPNGを復元できる |

Edgeのバージョン、各行の合否、表示されたエラーや画像を記録する。結果は[検証記録](T01_VALIDATION.md)に反映する。
