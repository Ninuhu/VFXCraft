# T01 技術検証記録

## Phase 2 描画技術（2026-11-04）

Three.js 0.186.1 と型定義 0.186.0 の公開情報を公式npmレジストリで確認し、pnpmで固定した。SpriteとOrbitControls、標準のUnrealBloomPassを使用する。粒子画像は検証コードがCanvas 2Dで生成した円形グラデーションで、外部素材は使用していない。

開発サーバーは `pnpm dev` で起動する。ブラウザで `http://127.0.0.1:5173/` を開く。通常2Dは640×360、ピクセル2Dは160×90を最近傍で表示する。粒子は最大64個の検証用スロットを用い、指定時刻から評価する。
