# VFXCraft プロジェクト仕様

版: 1.0 / 2026-11-03  
製品要件の正本。技術設計とUI配置は別文書で管理する。

## 1. 目的と基本方針

VFXCraftは2D・3Dゲームエフェクトを制作するWebブラウザ向けツール。初期開発目標を**MVP-B**と呼ぶ。プリセットまたは素材からエフェクトを作り、複数レイヤー、パーティクル、タイムライン、キーフレームで調整し、編集可能なプロジェクトとゲーム向け出力を得る。

- 初期プラットフォームはWebブラウザ。デスクトップアプリは将来対応。
- 2D・3Dを別々の編集モードとして提供する。
- UIのレイアウトとデザインはユーザーが決める。
- MVP-BではAIを必須にしない。AIなしで基本機能をすべて使える。
- CodexとGitHubを使う開発方針。リポジトリの作成・接続・公開はこの文書作成には含まない。

| ID | 要件 | 区分 |
| --- | --- | --- |
| REQ-Q10-01 | 専用拡張子`.vcr`で編集内容と素材を保存し、再編集できる | MVP-B必須 |
| REQ-Q10-02 | PNG連番で2Dアニメーションを出力する | MVP-B必須 |
| REQ-Q10-03 | スプライトシートで2Dアニメーションを出力する | MVP-B必須 |

保存とエクスポートは別の機能。`.vcr`の内部をZIPベースにする案と`project.json`・`assets/`・`metadata.json`の構成例は技術設計上の候補であり、採用決定ではない。

JSON出力は設定データであり、PNGのFPSや透過設定をそのまま必須引数にしない。3Dビューの画像出力、Unity等への専用インポーター、シート付随メタデータ形式は確定していない。

## 3. スコープの境界

| 区分 | 機能 |
| --- | --- |
| MVP-B必須 | Q1〜Q12・Q14の上記必須行すべて。2Dと3D、50種類以上の初期プリセット、基本Bloom、階層、最大100操作の履歴、自動保存を含む |
| 任意 | カーブエディタ。追加する場合もMVP-B必須機能の完了を優先 |
| MVP-B後 | デスクトップ版、キーフレーム対象の拡張、トレイル、メッシュパーティクル、カスタムシェーダー、高度なBloom、AI生成・編集・アドバイス |
| 採用未定の検討対象 | SQLite利用 |
| 要求が未定義 | Unity等の専用連携、共同編集、アカウント・クラウド保存など。勝手に実装対象へ追加しない |

## 4. MVP-Bの完成条件

1. Webブラウザ上で2Dと3Dそれぞれの制作フローが最後まで通る。
2. 連続発生・Burst、複数レイヤー、全必須描画方式が使える。
3. 位置・回転・サイズ・色・透明度のキー、開始時間、再生・コマ送り・速度・ループ、両スナップが機能する。
4. 階層、基本操作、ロック、最大100操作のUndo/Redo、指定された種類のショートカットが機能する。
5. 50種類以上の内蔵プリセットが読み込み・編集可能。自作プリセットの保存・読み込み・再編集、3画像形式の素材読込ができる。
6. `.vcr`保存→閉じる→開くで編集内容と素材が復元する。ブラウザ内自動保存からも復元できる。
7. 指定条件のPNG連番・スプライトシートを出力でき、3D設定JSONも出力できる。
8. カメラ・背景・統計表示、テーマ・日英切替・設定保持・ヘルプが機能する。
9. ユーザーが設計したUI配置が製品画面へ反映されている。仮画面のまま完成扱いにしない。
10. [TEST_PLAN.md](TEST_PLAN.md)の必須確認が完了し、既知の重大な不具合がない。

対応ブラウザ、基準端末、負荷条件、目標FPS、最大粒子数、最大出力サイズなどの具体値は未決。[DECISION_LOG.md](DECISION_LOG.md)の技術判断で実装前または該当工程前に定義する。未測定の性能を保証しない。
