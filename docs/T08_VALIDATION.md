# T08 タイムライン・キーフレーム・詳細再生 検証記録

`pnpm dev` を起動し、`/?timeline-review` を開く。サンプルで2D・3Dを切り替え、レイヤーとトラックを選ぶ。現在時刻にキーを追加し、マーカーのドラッグまたは数値入力で編集する。ファイル操作とUndo/Redoは画面下部。

## 確定仕様と確認方法

| 仕様 | 実装と確認 |
| --- | --- |
| Q01 ループ終端 | 整数µsの半開区間。手動シークは終端を含み、非ループは終端で停止。60FPS・2秒のフレーム119/120と実ブラウザの動作を確認する。 |
| Q02 発生期間 | 2D・3DのContinuousとBurstで開始を含め終了を除く。発生済み粒子の寿命境界を検証する。 |
| Q03 尺と発生期間 | 発生終了後のキーを許可する。尺の短縮は保持・削除・取消。削除と尺は一操作でUndoし、保持は警告と編集を維持する。 |
| Q04 キー編集 | 数値、ドラッグの仮表示、追加・削除・選択・区間補間を操作できる。 |
| Q05 ドラッグスナップ | キー・開始・明示終了マーカーに適用。秒の数値入力とシークに丸めを強制しない。 |
| Q06 横ズーム | 1〜16倍、スクロール、目盛り細分化と再生中のプレイヘッド追従。 |
| Q07 範囲 | 一括編集、カーブ、高度な合成はMVP-B後。 |
| Q08 区間補間 | 左キーのLinear／Step、3D姿勢のSLERP。単体値とブラウザの描画差を確認する。 |
| Q09 対象・決定性 | 変換、発生設定、粒子サイズ、材質色・透明度・Bloom、レイヤー色・透明度。可変発生率と発生時設定を2D・3Dで検証する。 |
| Q10 重複 | 同一トラック内のµs重複を拒否し、別トラックは許可。 |
| Q11 範囲外評価 | キーなしは基準値、新規トラックの先頭前・末尾後は端点を保持。版1〜4は先頭前の従来値を維持。 |
| Q12 衝突 | 初期フォーカスとEscapeは取消。確認済み上書きはUndo/Redoで両方のキーを復元する。 |
| Q13 表示・入力 | 秒・フレーム・制作FPSの変換と、FPS変更時のµs保持。 |
| Q14 再生速度 | 7段階と再生中の変更。保存値と編集履歴は再生時計から独立。 |
| Q15 再生操作 | 現在位置から再生、時刻を保つ一時停止、0へ戻る停止、コマ送りを用意。 |

[ADR-011](architecture/ADR-011.md)に発生率の積分、版5の移行、履歴の境界を記録した。固定の版1・2ファイルとテスト内生成の版3・4を読み、版5は発生期間・区間補間・範囲外キー保持を保存往復した。

## 制約と引き継ぎ

- 1回の評価候補を20万粒子に制限する。寿命が大きく変化する場合は、最長寿命を基に安全側に候補を見積もる。
- 正式UI v1.0の9枚は `foundation` の統合後に指定パスで確認した。2Dエディタの濃色・紫系の配色と下部タイムラインを参照した。製品UIはT10。
- T09の階層編集では、再親子化、階層ロックと時間・発生空間の関係を確認する。T13の出力は、制作フレームを同じ絶対時刻の評価器へ渡す。
