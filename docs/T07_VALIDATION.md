# T07 マテリアル・合成・背景・基本Bloom 検証記録

検証画面は `/?materials-review`。プロジェクト内で `pnpm dev` を起動し、2Dと3Dのサンプルを切り替える。保存・読込・Undo/Redoは画面下部。数値はEnterまたはフォーカス離脱で確定する。描画方式をピクセルへ切り替えると、Pixel BloomとSmooth Bloomを比較できる。

## 確定仕様と証拠

| 決定 | 実装 | 検証 |
| --- | --- | --- |
| Q01 寿命・空間 | CPUの正規化寿命とGPUのUV半径 | 寿命の境界・補間、2D寿命と3D空間の表示変化 |
| Q02 材質別Bloom | 正の強度を持つ材質だけ発光パスへ送る | 強度0・0.5・4の実画素比較、非発光材質と混在する見本 |

| Q04 背景 | 色・チェッカー・グリッド・グリッド透明度 | 共通設定からの継承、プロジェクト上書きと解除 |

| Q06 独立した複数制御点 | 色点と透明度点を別配列で保持 | 追加・削除・移動、異なる点数、重複拒否 |
| Q07 乗算 | RGBとアルファを独立に積算。画像は補間時にアルファ加重 | 単体の成分計算と半透明テクスチャの実画素 |
| Q08 3種の合成 | 通常・加算・乗算。2Dはレイヤー順、3Dは全体深度順 | 半透明粒子の通常・加算・乗算とカメラ反転 |
| Q09 共通半径・しきい値 | 共通の発光フィルターと材質強度 | 半径0としきい値1で粒子外の発光が消えること、設定往復と背景分離 |
| Q10 別々の描画と整数倍率 | 本体は最近傍、発光バッファで処理を分離 | 切替前後の実画像と同じ整数倍率での本体表示 |
| Q11 共通と個別保存 | 共通はlocalStorage、上書きは.vcr | false・0の保持、共通設定はプロジェクトの保存状態と独立 |
| Q12 正確と軽量 | 軽量は発光ぼかしの各辺を約1/2にする | 品質の切替、同じ粒子数・設定による性能比較 |

## 性能

Windows、Chrome 156・Edge 157のヘッドレス実ブラウザ。640×360、時刻0.5秒、Burst、2Dは1材質、3Dは2材質で、発光材質を一つ使用。半径12px、しきい値0.1。条件ごとにウォームアップ1フレームの後、同じ時刻を5フレーム描画したCPU側中央値。各ブラウザで23条件を実施し、計測ループはChrome約0.71秒、Edge約0.69秒。画素の読み戻しは計測外。

| モード | 粒子数 | Chrome 無効 / 正確 / 軽量 (ms) | Edge 無効 / 正確 / 軽量 (ms) |
| --- | ---: | ---: | ---: |
| 2D | 100 | 0.8 / 0.4 / 0.4 | 0.6 / 0.6 / 0.4 |
| 2D | 1,000 | 1.0 / 0.9 / 1.1 | 1.1 / 1.2 / 0.9 |
| 2D | 10,000 | 8.4 / 10.6 / 5.7 | 8.9 / 12.4 / 6.3 |
| 3D | 100 | 0.6 / 0.7 / 0.7 | 0.8 / 0.4 / 0.4 |
| 3D | 1,000 | 1.6 / 1.9 / 1.7 | 1.5 / 1.6 / 1.4 |
| 3D | 10,000 | 12.6 / 12.0 / 12.1 | 10.7 / 11.4 / 10.3 |

10,000粒子・正確時のCPU区間の中央値は、Chrome 2Dが評価3.2ms／データ準備6.2ms／本体0.5ms／Bloom 0.2ms。Chrome 3Dは評価4.6ms／ソート2.3ms／データ準備3.9ms／本体0.5ms／Bloom 0.3ms。Edgeは2Dが4.1／7.1／0.5／0.3ms、3Dが5.7／1.6／3.4／0.5／0.2ms。区間中央値の合計はフレーム全体の中央値と一致するとは限らない。

2Dの1,000粒子ではPixel／SmoothがChrome 1.4／0.9ms、Edge 1.2／1.1ms。通常／加算／乗算はChrome 0.9／0.9／1.2ms、Edge 1.2／1.2／1.4ms。3Dの1,000粒子を2材質から1材質共有へ切り替えると両ブラウザで4→3描画呼出し、テクスチャ3→2。1材質共有では両方の発生器が同じ発光強度になるため、時間は材質数だけの比較にならない。CPU頂点バッファ容量は128粒子で27,648B、1,000粒子で216,000B、10,000粒子で2,160,000B。3Dの低粒子数条件では先行条件のバッファを再利用する。

軽量品質の改善は条件によって異なり、Chrome 3Dの10,000粒子ではフレーム中央値が12.0→12.1msだった。シミュレーションとデータ準備のばらつきがBloom CPU区間の差より大きい。半解像度化はぼかしバッファの画素数を約1/4にするが、CPU測定ではGPU側の改善量を判断できない。GPU処理・転送の単独時間、実メモリ、連続再生の実測FPSは未計測。製品性能目標は未確定。

## 範囲と残件

- 正式UI v1.0の画像9枚は作業ツリーとT06統合時点の追跡対象に存在しない。T06記録にある履歴上の復元候補を維持し、今回の撮影は検証資料として区別する。
- 現行T07描画は開発用ルート。T10で正式UIへ統合する。共通設定の製品画面はT14。T07検証画面の2D表示には各辺2,048px、粒子数には20万件の技術上限がある。
- 材質が深度順に交互に並ぶと描画呼出しが増える。板の交差の画素順、遮光を含む高度Bloom、GPU側のプロファイルは別途検証対象。
- 単一の透過PNGで混在する加算・乗算の見た目を任意背景に再現できる範囲には限界がある。T13で出力時のアルファと背景、色空間、外部エンジンの設定を決める。
